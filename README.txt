Teplo Mail — файлы сайта для GitHub Pages

В архиве готовый статический сайт на английском и украинском.
Сборка, Node.js и Python не нужны.

Посмотреть на компьютере:
1. Распакуйте ZIP полностью, сохранив структуру папок.
2. Откройте index.html в браузере.

Опубликовать бесплатно:
1. Создайте отдельный ПУБЛИЧНЫЙ репозиторий сайта в GitHub.
   Для аккаунта t0rvu можно назвать его t0rvu.github.io,
   если такого репозитория ещё нет. Исходники приложения публиковать не нужно.
2. Загрузите файлы из архива и папки privacy, terms, contact, uk
   в корень репозитория. Не загружайте сам ZIP вместо файлов.
3. В Settings → Pages выберите Deploy from a branch → main → /(root).
4. Дождитесь успешной публикации GitHub Pages и откройте полученный адрес.

Внутренние ссылки относительные: сайт работает и в отдельном проектном репозитории.
Корневой index.html должен лежать рядом со style.css и theme.js.

Страницы:
index.html — английская главная
privacy/index.html — политика конфиденциальности
terms/index.html — условия
contact/index.html — поддержка
uk/ — украинские версии всех страниц

Почта поддержки: teplomailsupport@gmail.com.
Установщик приложения пока находится в закрытом GitHub-релизе:
для его скачивания нужен доступ к репозиторию приложения.
Архив содержит только сайт, без программы, баз клиентов, токенов и паролей.

После публикации пришлите адрес сайта: следующим шагом проверим страницы
для Google OAuth и настроим подтверждение владения через Search Console.
Размещение сайта само по себе не означает прохождения проверки Google.
