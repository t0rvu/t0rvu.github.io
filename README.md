# Teplo Mail website

Public website: https://t0rvu.github.io/

- English: `/`, `/privacy/`, `/terms/`, `/contact/`
- Ukrainian: `/uk/` and its corresponding pages
- Support: teplomailsupport@gmail.com

Static HTML, CSS and JavaScript. GitHub Pages publishes `main` from the repository root. No build is required. Keep the page folders intact when uploading changes.

Google Auth Platform links:
- Homepage: https://t0rvu.github.io/
- Privacy policy: https://t0rvu.github.io/privacy/
- Terms: https://t0rvu.github.io/terms/

Verify ownership through Google Search Console using a URL-prefix property and its HTML verification file or meta tag. Website publication does not itself complete Google OAuth verification.

This repository contains only the public website. The desktop application source and preview installer remain in a separate private repository.
